# Contributing

Found a bug? Open an issue with the command you ran and the output.

Want to add a feature? Open an issue first to discuss it, then a PR. Run `cargo test` before submitting.

## Dev setup

```bash
git clone https://github.com/glincker/sslx
cd sslx
cargo build
cargo test
```

## Before submitting a PR

- `cargo test` passes
- `cargo clippy` is clean
- `cargo fmt` has been run
